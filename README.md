# Читается?

Учебный React-проект для проверки контраста текста и фона. Можно выбрать цвета, посмотреть пример и получить CSS для выбранной пары.

## Возможности

- Выбор цвета через палитру или HEX-поле.
- Поддержка короткого HEX: `#fff`, и обычного: `#ffffff`.
- Расчёт контраста и проверка требований AA/AAA к тексту.
- Живой предпросмотр с настройкой размера текста.
- Перестановка текста и фона, четыре готовых примера.
- Копирование CSS и адаптивная вёрстка.

## Стек

React, JavaScript, CSS, Vite. Без сервера, API и UI-библиотеки. Цвета не отправляются на сервер, всё вычисляется в браузере. После перезагрузки открывается начальная пара.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Открой адрес из терминала.

```sh
npm test         # проверка формата цветов и расчётов
npm run build    # сборка в dist
npm run preview  # просмотр сборки
```

## Структура

```text
src/
  App.jsx         — цвета, результаты и предпросмотр
  ColorField.jsx  — поле выбора одного цвета
  colors.js       — HEX, яркость, контраст и пороги
  colors.test.js  — проверки расчётов
  main.jsx        — точка входа
  styles.css      — стили и мобильная версия
```

## Как считается контраст

HEX переводится в три канала RGB. Каналы линеаризуются по формуле sRGB, затем рассчитывается относительная яркость. Контраст равен `(светлая яркость + 0.05) / (тёмная яркость + 0.05)`.

Для обычного текста порог AA — 4.5:1, для крупного — 3:1. Для обычного текста AAA — 7:1. На экране число округляется, но пороги проверяются по исходному значению: 4.4999 не считается прохождением AA.

Формулы и пороги: [WCAG — Contrast Minimum](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html) и [Contrast Enhanced](https://www.w3.org/WAI/WCAG21/Understanding/contrast-enhanced).

`ColorField` получает цвет и обработчик через props. В `App` цвета хранятся в `useState`. Результат вычисляется из текущих цветов при рендере. Отдельное состояние для вычисленного контраста не нужно.

При неправильном HEX расчёт и предпросмотр не показываются. После исправления они появляются снова. Кнопка перестановки меняет порядок цветов; само отношение контраста остаётся прежним.

## Ограничения

Только непрозрачные HEX-цвета в sRGB. Прозрачность, градиенты и фоновые изображения не учитываются. Это проверка контраста текста, а не аудит доступности всей страницы. Кнопка копирования зависит от разрешений браузера; код можно выделить вручную.

## Ручная проверка

1. Выбрать чёрный и белый: результат 21:1.
2. Выбрать одинаковые цвета: результат 1:1.
3. Нажать «Поменять местами»: контраст не меняется.
4. Ввести ошибочный HEX: появляется подсказка, копирование отключается.
5. Выбрать «Слабый контраст»: проверки не проходят.
